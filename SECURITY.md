# Security policy

YAGA is security-sensitive GitHub Actions infrastructure. Please do not open a
public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting for this repository. Include the
affected commit, the trust boundary involved, the expected fail-closed
behavior, and a minimal reproduction that contains no credentials or private
repository data.

Supported versions will be listed after the first canary-backed release. Until
then, consumers must pin the exact audited commit SHA they tested.
